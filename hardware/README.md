# 🛠️ AgroHomeSystem — Аппаратная часть и 3D-модели (Hardware & CAD)

В данной директории собраны все трёхмерные модели, чертежи и спецификации для аддитивного производства (3D-печати) и сборки корпуса автономного агро-инкубатора **AgroHomeSystem** (габариты базового модуля: **260 × 200 мм**).

---

## 🖨️ Рекомендации по 3D-печати

| Параметр | Значение | Примечание |
|:---|:---|:---|
| **Материал** | **PETG / ABS / ASA** | Высокая влагостойкость и УФ-стабильность к фитоосвещению. *(Не рекомендуется использовать обычный PLA из-за гидролиза в теплой влажной среде)*. |
| **Высота слоя** | **0.20 мм** (0.16 мм для петель и штырей) | Оптимальный баланс прочности и герметичности. |
| **Заполнение (Infill)** | **25 – 40% (Gyroid / Grid)** | Обеспечивает жесткость корпуса при заполнении раствором. |
| **Периметры (Стенки)** | **4 – 5 линий** | Критически важно для 100% герметичности нижнего резервуара. |
| **Ориентация купола** | Плоской гранью к столу | Минимизирует использование поддержек. |

## 🔩 Спецификация и крепеж

1. **Сервопривод купола:** Высокомоментный влагозащищенный сервопривод (напр. *MG996R / DS3218*) или шаговый двигатель *NEMA 17*.
2. **Поворотные петли:** Напечатанные штифты `Штырь 10мм` / `Штырь 9мм` либо винты M4×35 с самоконтрящимися гайками.
3. **Камера:** Модуль камеры Raspberry Pi Camera V2 / V3 или широкоугольная USB-камера со шлейфом/кабелем, проложенным через кабельный канал задней стенки.
4. **Посадочные места:** 8 ячеек под субстратные кубики и пробки из минеральной ваты 22 мм (Grodan) или кокосовые пробки.
