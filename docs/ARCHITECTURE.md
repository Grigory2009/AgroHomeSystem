# 🏛️ Архитектура системы AgroHomeSystem

## 1. Введение
Проект **AgroHomeSystem** представляет собой киберфизическую систему (CPS) для автономного микрорастениеводства. Система объединяет механику 3D-печатного герметичного бокса, встроенное микроконтроллерное управление на базе ESP32-S3 и Edge AI компьютерное зрение для контроля биомассы и здоровья культур в режиме реального времени.

```
+-------------------------------------------------------------------------+
|                           AgroHomeSystem Node                           |
|                                                                         |
|  +------------------------+                  +-----------------------+  |
|  |     ESP32-S3 Core      |                  |   Raspberry Pi / Host |  |
|  |  (FreeRTOS Control)    |                  |        (Edge AI)      |  |
|  |                        |                  |                       |  |
|  | - pH, TDS, Temp Sens   |                  | - Wide-Angle Camera   |  |
|  | - Ebb & Flow Pump      |<--- Wi-Fi/MQTT-->| - YOLOv8/11-seg       |  |
|  | - Active Lid Servo     |                  | - ViT Disease Class   |  |
|  | - 2.8" TFT Touch GUI   |                  | - SQLite Database     |  |
|  | - Embedded Web Server  |                  | - Streamlit Dashboard |  |
|  +------------------------+                  +-----------------------+  |
|               ^                                           ^             |

                |                                           |
                v                                           v
   +-------------------------+                 +-------------------------+
   |   ESP-NOW Swarm Mesh    |                 | Home Assistant / Cloud  |
   |   (Inter-module sync)   |                 | (Centralized Analytics) |

```

## 2. Подсистемы

### 2.1. Механическая подсистема (Ревизия v2)
- **Корпус:** Эргономичный компактный бокс 260 × 200 мм (3D-модели `Корпус нижняя часть v2.stp`, `Ячейки.stp`).
- **Сетка ячеек v2:** 24 посадочных гнезда (сетка 4×6) под субстратные пробки минеральной ваты 22 мм (Grodan / кокос).
- **Нижний бак:** Интегрированный гидропонный резервуар периодического затопления с дренажным уклоном.
- **Активный купол:** Откидная крышка с сервоприводом (угол 0°..65°) для естественной терморегуляции и вентиляции без шума кулеров.

### 2.2. Микроконтроллерная подсистема (ESP32-S3)
- Двухъядерный 32-битный процессор Xtensa LX7 (240 MHz, 8MB Flash).
- Раздельные шины SPI: HSPI для ILI9341 (320x240) и FSPI для XPT2046 Touch.
- Расчет агрономических коэффициентов (VPD по формуле Тетенса).
- Автоматический цикл гидропоники Ebb & Flow (15 мин затопление / 45 мин аэрация).
- **Беспроводное обновление прошивки (OTA Engine):**
  - Web OTA (`http://<ip>/update`): веб-интерфейс загрузки `firmware.bin` с прогресс-баром.
  - ArduinoOTA (порт 3232, хост `agrobox-esp32s3.local`): прямая прошивка из PlatformIO.
  - Визуализация на TFT 2.8": отображение прогресса прошивки и авто-перезагрузка.

### 2.3. Подсистема компьютерного зрения (Edge AI)
- Камера охватывает всю площадь посадочного лотка.
- **24-Cell Matrix Tracker (`demo/cell_tracker.py`):**
  - Индивидуальный трекинг 24 ячеек (сетка 4×6) в реальном времени (<3 мс).
  - Вычисление площади покрытия (Canopy Cover %), хлороза, некроза и очагов плесени (*Botrytis*).
  - Определение стадий развития семян/ростков для каждого посадочного гнезда отдельно.
- **MobileNetV2 Watercress Edition ONNX:** Классификация стадий и патологий микрозелени.
- **Спектральный анализ:** Контроль хлороза в цветовом пространстве HSV и индекса ExG.

### 2.4. Роевая сеть (Swarm Farming)
- Автономная координация группы инкубаторов на стеллажах.
- Децентрализованный обмен через ESP-NOW и публикация телеметрии по MQTT.
